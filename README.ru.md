# wg-stats

[English](README.md) · **Русский**

Простая самостоятельно размещаемая панель, которая в реальном времени
показывает состояние ваших пиров **WireGuard / AmneziaWG** на одном или
нескольких серверах — кто онлайн, скорость, общий объём трафика и время с
последнего рукопожатия. На каждом сервере работает небольшой скрипт на Python,
который считывает туннели и отправляет снимок состояния на один сервер с
панелью; одна веб-страница показывает всё это и обновляется каждые пару секунд.

Без базы данных, без фреймворков, без сборки — три части: скрипт-сборщик (по
одному на сервер), несколько JSON-файлов и одна HTML-страница.

## Как это работает

```
  сервер 1 ── collector.py ─┐
  сервер 2 ── collector.py ─┤  копирует статистику по SSH  ►  сервер с панелью (nginx)
  сервер 3 ── collector.py ─┘                                  ├── index.html    ← панель
                                                                ├── users.json    ← кто есть кто (приватно)
                                                                └── stats-*.json  ← загружают сборщики
                                                                          ▲
                                                              ваш браузер обновляет страницу
```

1. На каждом сервере `collector.py` считывает вывод `wg`/`awg show … dump`,
   вычисляет скорость каждого пира и записывает файл `stats-<имя>.json`.
2. Этот файл копируется на сервер с панелью через `rsync` по SSH.
3. `index.html` (его раздаёт nginx на сервере с панелью) загружает `users.json`
   (имена и цвета) и все файлы `stats-*.json` и показывает живую таблицу.

## Что в этом репозитории

| файл | куда устанавливается | что это |
|------|----------------------|---------|
| `index.html` | сервер с панелью | страница панели |
| `users.example.json` | сервер с панелью | пример списка — скопировать в `users.json` |
| `collector.py` | каждый узел | читает туннели, загружает статистику |
| `wg-stats-collector.service` | каждый узел | запускает сборщик в фоне |
| `nginx.conf.example` | сервер с панелью | пример конфигурации веб-сервера |
| `.gitignore` | — | держит приватные файлы вне git |

## Что нужно перед началом

- **Один сервер с панелью** — с nginx и доменным именем; на нём размещается
  веб-страница. Это может быть один из ваших существующих серверов.
- **Один или несколько узлов** — серверы с WireGuard/AmneziaWG, которые вы
  хотите мониторить.
- Доступ root / `sudo` на каждом, а также `python3` и `rsync` (обычно уже
  установлены).

Сервер с панелью может быть одним из узлов — это нормально.

## Часть A — Настройка сервера с панелью

**1. Создайте папку и скопируйте веб-файлы:**
```bash
sudo mkdir -p /opt/wg-stats
sudo cp index.html users.example.json /opt/wg-stats/
```

**2. Создайте рабочий список из примера:**
```bash
sudo cp /opt/wg-stats/users.example.json /opt/wg-stats/users.json
```

**3. Закройте страницу паролем** (чтобы она не была публичной):
```bash
sudo apt install -y apache2-utils
sudo htpasswd -c /etc/nginx/wg-stats.htpasswd myusername
```

**4. Добавьте сайт в nginx.** Откройте `nginx.conf.example`, замените
заполнители `YOUR_...` (ваш домен, порт и пути к TLS-сертификатам — если
сертификатов ещё нет, их бесплатно выдаст [certbot](https://certbot.eff.org/)),
затем:
```bash
sudo nano /etc/nginx/sites-available/wg-stats     # вставьте отредактированный конфиг
sudo ln -s /etc/nginx/sites-available/wg-stats /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

Откройте ваш домен в браузере — вы должны увидеть панель (пока пустую и с
запросом пароля, который вы задали).

## Часть B — Настройка панели

Откройте `/opt/wg-stats/index.html` и найдите блок **CONFIG** в начале.

**1. Перечислите серверы (`NODES`)** — по одной строке на каждый:
```js
const NODES = {
  "berlin": { file:"stats-berlin.json", color:"#b387f5" },
  "paris":  { file:"stats-paris.json",  color:"#6cb6ff" },
};
```
- **Ключ** (`"berlin"`) — это подпись на значке, и он же задаёт его цвет.
- **`file`** должен совпадать с именем файла, который создаёт сборщик на сервере
  (вы зададите это в Части C). Если сборщик пишет `stats-berlin.json`, укажите
  здесь `file:"stats-berlin.json"`.
- `color` — цвет значка, когда сервер онлайн. `border` и `label` необязательны.

**2. IP turn-proxy (`TURN_IPS`)** — только если вы используете turn-proxy.
Перечислите публичные IP; пиры, подключающиеся через них, получают значок 📡.
Иначе оставьте заполнитель:
```js
const TURN_IPS = ["203.0.113.10"];
```

**3. Пиры не из списка (`SHOW_UNLISTED`)** — оставьте `false`, чтобы
показывались только те, кто есть в `users.json`.

Теперь отредактируйте `/opt/wg-stats/users.json` — он сопоставляет публичный
ключ каждого пира с именем:
```json
{
  "<публичный ключ>": { "name": "Alice", "ip": "10.0.0.2", "if": "wg0", "type": "user", "node": "berlin" }
}
```

| поле | значение |
|------|----------|
| `name` | отображаемое имя |
| `ip` | IP в туннеле (необязательно) |
| `if` | интерфейс (`wg…` → «wireguard», `awg…` → «amnezia») |
| `type` | `user` или `router` — две отдельные таблицы |
| `node` | сервер — должен совпадать с ключом в `NODES` |

Публичный ключ пира можно посмотреть командой `wg show <интерфейс>` (или
`awg show <интерфейс>`) на сервере.

## Часть C — Сборщик на каждом узле

Сделайте это на **каждом** сервере, который хотите мониторить.

**1. Скопируйте файлы:**
```bash
sudo mkdir -p /opt/wg-stats
sudo cp collector.py /opt/wg-stats/
sudo cp wg-stats-collector.service /etc/systemd/system/
```

**2. Создайте SSH-ключ**, чтобы этот сервер мог загружать файлы на сервер с
панелью, и авторизуйте его там:
```bash
sudo ssh-keygen -t ed25519 -f /root/.ssh/wg-stats_ed25519 -N ""
sudo ssh-copy-id -i /root/.ssh/wg-stats_ed25519.pub -p YOUR_PORT user@VIEWER_IP
```

**3. Отредактируйте блок CONFIG в `collector.py`:**
```python
INTERFACES = [("wg0", ["wg"])]                  # ваши интерфейсы и инструмент
NODE       = "berlin"                            # короткое имя сервера -> stats-berlin.json
RSYNC_DEST = "user@VIEWER_IP:/opt/wg-stats/"
SSH_KEY    = "/root/.ssh/wg-stats_ed25519"
SSH_PORT   = "22"
```
- `INTERFACES` — каждая запись это `(имя_интерфейса, команда)`. Используйте
  `["awg"]` для AmneziaWG, `["wg"]` для WireGuard или
  `["docker","exec","<контейнер>","wg"]`, если он работает в Docker (например,
  wg-easy).
- `NODE` — из него получается имя файла `stats-<NODE>.json`, и оно **должно
  совпадать** с `file:` в `index.html`.

**4. Сначала запустите вручную для проверки:**
```bash
sudo python3 /opt/wg-stats/collector.py
```
Дайте поработать несколько секунд, затем Ctrl-C. На сервере с панелью проверьте,
что файл `stats-<NODE>.json` появился в `/opt/wg-stats/`.

**5. Запустите как фоновую службу:**
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now wg-stats-collector
sudo journalctl -u wg-stats-collector -f          # следите за ошибками
```

Повторите на каждом сервере и обновите панель — ваши пиры должны появиться.

## Безопасность — обязательно прочитайте

**`users.json` связывает публичные ключи с реальными людьми. Относитесь к нему
как к файлу с паролями.**

- **Никогда** не добавляйте в git `users.json`, приватные ключи, файл с паролем
  и актуальные `stats-*.json`. Включённый `.gitignore` их уже блокирует —
  выполните `git status` перед первым коммитом, чтобы убедиться, что их нет в
  списке.
- Держите панель за паролем **и** за HTTPS — это список ваших пользователей.
- В том, что публикуете, используйте заполнители вместо реальных IP, портов и
  доменов.

## Решение проблем

| симптом | что делать |
|---------|------------|
| сервер показан как **«down»** | панель не может прочитать его файл статистики — проверьте, что сборщик работает и rsync проходит (`journalctl -u wg-stats-collector`) |
| сервер показан как **«stale»** | сборщик остановился или загрузка не проходит |
| ошибка **403** на файле статистики | nginx не может его прочитать; сборщик загружает с `--chmod=F644`, а `/opt/wg-stats` должна быть доступна nginx на чтение |
| **список пуст** / ошибка users.json | файл `users.json` отсутствует или содержит неверный JSON |
| пир показан длинным кодом, а не именем | его нет в `users.json` (или `SHOW_UNLISTED` = `true`) |
